## Architecture Overview

The server remains authoritative. `membership-catalog.server.ts`, the independent commercial-availability policy, and `metering-catalog.server.ts` are composed by the new read-only `GET /api/membership/tool-costs` endpoint. The endpoint exposes only action code, customer label, credit cost, and a derived enabled boolean; it cannot accept request data or mutate a wallet. The existing safe wallet endpoint supplies current balance, grant/reset, pending holds, and bounded normalized history.

The browser parses both responses with exact-key runtime validators in `membership-wallet-presentation.ts`. `CreditWalletProvider` fetches the two projections in parallel with `no-store`, keeps the Credits tab available when only tool costs fail, and fails all generation closed unless wallet and action state agree. `useToolCreditState` derives loading, unavailable, disabled, insufficient, and ready states.

Metered clients translate stable route codes through `metering-customer-presentation.ts` into reserved, committed, returned, retry, reconciliation, capacity-paused, or disabled presentation. Retries retain the original request UUID and customer input. The three metered routes now include a next-UTC-month `resetAt` only for `READER_AI_CAPACITY_PAUSED`; authorization, provider, persistence, reservation, settlement, and commercial guards were not changed.

## Key Patterns Discovered

- Customer projections use exact-key parsers; unknown fields are rejection conditions, not ignored.
- Availability is the intersection of independent server truths. A catalog, commercial, quote, mode, offer, or kill-switch mismatch closes the action.
- Wallet read failure closes all generation. Tool-cost read failure closes tools without hiding a valid wallet from the Credits tab.
- Idempotent retries reuse the same UUID and preserve customer text. Do not clear request IDs for ambiguous in-progress/replay states or clear inputs after errors.
- Reader capacity messaging is scoped to Reader generation and an exact UTC boundary. Paid-member generation and non-generative reading/search/Graph/Journal/saved-result access must stay available.
- Mobile balance cells intentionally use extra left padding because an existing fixed utility widget otherwise overlaps the Reserved numeral at 375px.
- UI evidence fixtures must be localhost-only, marker-owned, synthetic, and verified residue-free.
